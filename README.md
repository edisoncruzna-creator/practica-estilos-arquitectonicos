# Práctica: estilos arquitectónicos

**Diseño y Arquitectura de Software · Unidad 1**
Docente: Ing. Edison Cruz Navarrete, Mgtr.

Un mismo problema, la gestión de estudiantes y sus notas, resuelto con cinco estilos.
Todos usan los mismos datos: `datos/estudiantes.csv`.

| Carpeta | Estilo | Sesión |
| --- | --- | --- |
| `1_tuberias_filtros/` | Tuberías y filtros | 1 |
| `2_capas/` | Por capas | 1 |
| `3_cliente_servidor_rest/` | Cliente-servidor y REST | 2 |
| `4_mvc/` | Modelo-Vista-Controlador | 2 |
| `5_eventos/` | Dirigido por eventos | 2 |

## Cómo empezar

1. Pulsa **Use this template → Create a new repository** y crea tu copia.
2. En tu copia pulsa **Code → Codespaces → Create codespace on main**.
3. Espera a que se instale todo (1 a 2 minutos). Verás VS Code en el navegador.
4. Abre la terminal (menú **☰ → Terminal → New Terminal**) y entra a la carpeta del estilo.

Cada carpeta tiene su propio `README.md` con los pasos y ejercicios.

## Guardar tu trabajo

```bash
git add .
git commit -m "Práctica estilos: sesión 1"
git push
```

Al terminar, **detén el Codespace** (github.com/codespaces → ⋯ → Stop) para no gastar tus horas gratuitas.
